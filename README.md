## Overview
This project aims to create an interactive and visually appealing website for KRC. It provides detailed information about the school's activities, programs, faculty, and other relevant content in a user-friendly format.

## Features
- Fully **responsive layout** compatible with all devices.
- **Dynamic navbar and footer** for consistent site navigation.
- **Interactive content sections** to showcase school programs and events.
- **Optimized images and media** for fast loading and accessibility.
- Clean and modern **UI/UX design** using Bootstrap.

## Technologies Used
- **HTML5** – for webpage structure
- **CSS3** – for styling and layout
- **JavaScript** – for interactivity
- **Bootstrap** – for responsive design and components
